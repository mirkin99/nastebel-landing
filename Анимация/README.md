# NASTEBEL — изометрическая анимация

Откройте index.html в браузере. Все стили, рисунки SVG и логика встроены в файл. Интернет, сборка и сторонние библиотеки не нужны.

Сценарий: два цветочных склада с парковками → мастерская и сборка трёх букетов → три клиента → возвращение, сообщение о новом заказе → повтор.

Управление: пауза, запуск сначала, скорость, перемотка, переход к этапам и зданиям, масштаб. На телефоне сцену можно перемещать горизонтальным свайпом. При системной настройке уменьшения движения требуется нажать «Продолжить».

Это отдельный прототип. Для встраивания на основной сайт потребуется согласовать внешний вид и адаптацию блока.
